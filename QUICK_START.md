# Travel.Zilla - Quick Start Guide

## 🚀 Getting Started in 3 Steps

### Step 1: Install Dependencies
```bash
cd zilla
npm install
```

### Step 2: Start Development Server
```bash
npm run dev
```

### Step 3: Open in Browser
```
http://localhost:5173/
```

✅ **Application is now running!**

---

## 📱 Features to Try

### 1. **Real-Time Navigation**
- Look at the top-right of the navigation bar
- Current date and time updates every second

### 2. **Browse Destinations**
- Click "Waterfalls", "Mountains", "Beaches", or "Camping" in the menu
- See all 10 destinations for each category
- Click any card to view detailed information

### 3. **Search**
- Use the search bar in navigation
- Try searching: "falls", "mountain", "beach", "camping"
- See instant results across all 40 destinations

### 4. **View Details**
- Click "View Details" on any destination
- See complete information including:
  - Distance from Colombo
  - Best season to visit
  - How to reach (directions)
  - Special features
  - Activities available
  - Google Maps link

### 5. **Chat Support**
- Click the floating chat button (bottom-right)
- Fill out the contact form
- Submit your message

### 6. **Responsive Design**
- Resize your browser window
- Watch the layout adapt to different sizes
- Try it on mobile (or use DevTools)
